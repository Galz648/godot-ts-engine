# Handover: typed asset & script path registry (PoC 1)

Sep 30, 2026 · @HUMONGOUSCOCKOUS

## Context and goal

Build a small script that scans a Godot project and generates a TypeScript file of every texture, scene and script path, typed as string literals. A typo in a path then becomes an ordinary TypeScript error, with no type-level tricks.

This is the first of four separate proofs of concept. The later ones (a .tscn emitter, a structural validator, a language service plugin) will consume this registry, but none of them is part of this task.

The approach is deliberate: enforcement comes from generated code plus plain TypeScript, not from complex intersection or conditional types. If a check can't be expressed as a simple literal union, it does not belong in this PoC.

## Scope

In scope:

- Recursively scan a Godot project root (the folder containing project.godot).
- Collect textures (.png, .jpg, .jpeg, .webp, .svg), scenes (.tscn) and scripts (.gd).
- Skip .godot/, node\_modules/, .git/ and any .import sidecar files.
- Emit one generated file with the paths as res:// strings.
- A --watch flag that regenerates when files are added, removed or renamed.

Out of scope:

- Emitting or editing .tscn files.
- Validating scene structure (e.g. CharacterBody2D needs a collision shape).
- Any language service plugin or editor integration.
- Changes to tstogd itself, or reading its config.

## Deliverables and output shape

Three things: the generator script, the generated file checked into a tiny sample project, and a short session note.

1. `tools/gen-registry.ts` — runnable with `npx tsx tools/gen-registry.ts <projectRoot> [--watch]`. Node built-ins only (fs, path); no framework, no Effect.
2. `src/registry.gen.ts` — the generated output, with a "do not edit" header.
3. `sample/` — a minimal Godot project with a couple of textures, one scene and one script, used by the experiments below.
4. `SESSION.md` — intent, tasks, what was completed, findings, next steps.

Target shape of the generated file:

```ts
// AUTO-GENERATED by tools/gen-registry.ts. Do not edit.
export const Textures = {
  ball: "res://art/ball.png",
  paddle: "res://art/paddle.png",
} as const;
export type TexturePath = (typeof Textures)[keyof typeof Textures];

export const Scenes = { main: "res://main.tscn" } as const;
export type ScenePath = (typeof Scenes)[keyof typeof Scenes];

export const Scripts = { ball: "res://scripts/ball.gd" } as const;
export type ScriptPath = (typeof Scripts)[keyof typeof Scripts];
```

Rules for the output:

- Keys are camelCased file stems; on a collision, include the folder (e.g. `artBall`, `uiBall`).
- Entries sorted by path, so the output is deterministic and diffs cleanly.
- Write the file only if its contents changed, to avoid retriggering watchers.
- A consumer function signature, to prove the types work: `function sprite(texture: TexturePath) {}`.

## Acceptance criteria

Done means each experiment below runs by hand and behaves as described. Record the actual output of each in SESSION.md.

- [ ] Running the generator on `sample/` produces `registry.gen.ts` matching the shape above.
- [ ] Running it twice in a row leaves the file byte-identical (and untouched on disk).
- [ ] `sprite(Textures.ball)` and `sprite("res://art/ball.png")` both compile with `tsc --noEmit`.
- [ ] `sprite("res://art/bal.png")` fails `tsc` with a plain "not assignable to TexturePath" error.
- [ ] Adding `sample/art/wall.png` and regenerating makes `Textures.wall` available.
- [ ] Deleting `ball.png` and regenerating turns every use of it into a type error.
- [ ] With `--watch`, adding or deleting a texture updates the file within about a second.
- [ ] Files under `.godot/` and `*.import` never appear in the output.

## Constraints and what comes next

Keep it small: one script, well under 200 lines, readable top to bottom. Prefer obvious code over clever code; no abstractions for later PoCs.

- Must work on Windows: normalize backslashes to forward slashes before building res:// paths.
- Time-box: stop after about two hours and write up findings, even if unfinished.
- If something is ambiguous, pick the simplest option and note it in SESSION.md rather than asking.

Later PoCs, not part of this task: a .tscn emitter that takes `ScriptPath` and `TexturePath` values; a validator for structural rules; a language service plugin that surfaces validator errors as editor squiggles.
