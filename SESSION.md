# PoC 1 session: typed asset & script path registry

Date: 2026-09-30. Spec: `pocs/Handover typed asset & script path registry (PoC 1).md`.

## Intent

Prove that a scan of a Godot project can be turned into generated string-literal unions, so a path typo is
an ordinary TypeScript error. No type-level tricks; enforcement is generated code plus `tsc`.

## Tasks

1. Bun project in `pocs/poc1-registry/` (own `package.json`, `tsconfig.json`, TypeScript pinned `~5.9`).
2. `sample/`: minimal Godot project (two 1x1 PNGs, `main.tscn`, `scripts/ball.gd`, a `ball.png.import` sidecar).
3. `tools/gen-registry.ts` (122 lines, `node:fs`, `node:path`, `node:url` only): scan, key, render, write-if-changed, `--watch`.
4. `src/registry.gen.ts` (generated) and `src/consumer.ts` (`sprite(texture: TexturePath)`).
5. Run every acceptance check by hand; record below.

All 8 acceptance checks ran and passed (details below). Not tested: Windows (no Windows machine here).

## Findings and surprises

- **tstogd does not fully honour `exclude`.** `pocs/` lives inside the tstogd project root, and tstogd scans the
  whole root for scenes and assets. With `"exclude": ["pocs/**"]`, `tstogd convert` still generated
  `src/_typings/pocs/poc1-registry/sample/main.tscn.d.ts` and `src/_typings/_resources.d.ts` (the sample PNGs).
  Adding the folder itself, `"exclude": ["pocs", "pocs/**"]`, stopped all of it. Root `tstogd.json` now has both.
  A `tstogd watch` that was already running needs a restart to pick this up.
- **TypeScript 7 vs 5.9.** `bun add typescript` would install 7.0.2 (the native port). I pinned `~5.9`, because tstogd
  needs the classic API and PoC 4 (language service plugin) will too. PoC 1 only needs `tsc`.
- **Nested Godot project.** `sample/` has its own `project.godot`, inside the repo's real Godot project. Godot skips
  folders that contain a `project.godot`, so the editor should ignore it. I did not open the editor to confirm.
- **`.import` files** are skipped by name, and also fall out naturally because `.import` is not a listed extension.
- **`fs.watch` recursive** worked on macOS with Bun. Node 20+ supports it on Linux too, but I did not test Linux.

## Decisions to review

1. **Bun, not `npx tsx`.** The handover says `npx tsx tools/gen-registry.ts`. You asked for Bun projects, so the
   scripts run with `bun`. The file itself uses only Node built-ins and should run unchanged under `tsx`. I did not
   run it under `tsx`.
2. **Output location** is fixed to `src/registry.gen.ts` next to the script, not configurable.
3. **Sorting** is plain code-unit order on the `res://` path, so it's the same on every machine (not locale-aware).
4. **Key collisions beyond the spec:** folder first, then extension, then a numeric suffix as a last resort.
   The numeric suffix path was not exercised.
5. **Symlinked directories** are not followed.
6. **`sample/` PNGs** are 1x1 images generated by a Python one-liner, not real art.
